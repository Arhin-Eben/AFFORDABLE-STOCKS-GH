# Affordable Stocks GH - E-Commerce Platform

A beautiful, production-ready, scalable, mobile-responsive e-commerce platform built with modern technologies and cool animations.

## 🏗️ Architecture

### Frontend Stack
- **React** - UI library
- **Vite** - Fast build tool
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Zustand** - State management
- **React Query** - Data fetching & caching

### Backend Stack
- **Node.js** - Runtime
- **Express** - Web framework
- **PostgreSQL** - Database
- **Prisma** - ORM
- **Redis** - Caching & session management
- **JWT** - Authentication

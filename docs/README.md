# Affordable Stocks GH Documentation

## Quick Start

```bash
docker-compose up -d
```

## Frontend
- React 18 + Vite + TypeScript + Tailwind + Zustand

## Backend
- Node.js + Express + PostgreSQL + Prisma

## Features
- ✅ User authentication
- ✅ Product catalog
- ✅ Shopping cart
- ✅ Order management
- ✅ Admin dashboard

See individual README files in frontend/ and backend/ directories for detailed setup.
